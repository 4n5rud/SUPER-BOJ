# 백준 연동

공식 이용 규칙은 웹 스크래핑을 금지하며, 브라우저의 공식 `/submit` 화면에서 사용자가 직접 제출하도록 요구합니다. SUPER_BOJ는 현재 열려 있는 페이지에서 문제·채점 정보를 읽습니다. 제출 단계에서는 소스 복사와 공식 페이지 열기를 제공하고 사용자가 직접 붙여넣고 제출합니다. DOM에서 확인할 수 없는 정보는 사용자 입력과 확인을 거칩니다. [BOJ 이용 규칙](https://help.acmicpc.net/rule) · [자동 제출 관련 공지](https://www.acmicpc.net/board/view/165526)

## 확인한 구조

- 공개 문제 페이지에서 `#problem_title`과 `sample-input-N`, `sample-output-N` ID를 확인했습니다. 테스트는 핵심 DOM 형태를 재현한 소규모 fixture를 사용합니다. [1000번 문제](https://acmicpc.net/problem/1000)
- 공개 채점 현황에서 `#status-table`과 `result-text` 요소를 확인했습니다. 채점 현황은 사용자가 연 탭의 DOM 범위에서 확인합니다. [1000번 채점 현황](https://acmicpc.net/status?problem_id=1000)
- 비로그인 사용자가 `/submit/1000`으로 이동하면 로그인 화면이 나타나는 것을 확인했습니다. 로그인 후 제출 폼, 실제 제출 후 이동 경로, 본인 제출 코드 열람은 수동 검증이 필요합니다. [공식 제출 경로](https://acmicpc.net/submit/1000)
- `www.acmicpc.net`을 사용하는 링크는 서비스 설정에 따라 `acmicpc.net`으로 연결됩니다. 확장은 두 HTTPS 호스트를 지원합니다.

2026-11-27에 공식 도움말과 자동 제출 공지를 다시 확인했습니다. 이번 확인 환경에서는 공개 채점 현황과 제출 URL을 다시 열 수 없었으므로, 위 DOM 관찰은 초기 검증 기록을 유지합니다. 공식 규칙에는 확장의 DOM 읽기를 명시적으로 허용하는 조항이 확인되지 않았습니다. [BOJ 이용 규칙](https://help.acmicpc.net/rule) · [자동 제출 관련 공지](https://www.acmicpc.net/board/view/165526)

## 연결 규칙

사용자가 실제 제출 번호, 문제, 언어, 계정, 제출 소스를 눈으로 확인한 뒤 준비 기록과 연결합니다. 공식 제출 화면에서 소스가 달라졌다면 실제 제출 소스와 원래 준비한 스냅샷을 대조해야 합니다. 최신 행이라는 이유로 제출을 자동 연결할 수 없습니다. 확인할 수 없는 채점 수치는 비워 두고, 알 수 없는 채점 문자열은 원문을 보존합니다.

대회는 일반 문제·제출 흐름과 별도로 취급합니다. 대회에서 사용하거나 풀이를 공유하기 전에는 대회 규정을 확인합니다. [백준 대회 규칙](https://help.acmicpc.net/contest/rule)
