# ADR 0002 · 공식 제출과 기록 연결

## 맥락

백준은 공식 페이지에서 사용자 직접 제출을 요구합니다. 사용자가 복사 후 코드를 변경할 수 있고, 동일 시간대에 다른 제출이 발생할 수 있습니다.

## 결정

제출 준비 시 원본을 스냅샷으로 저장하고 공식 제출 경로를 열어 사용자가 직접 제출하게 합니다. 실제 시도 연결에는 제출 ID와 실제 제출 코드가 일치한다는 근거가 필요합니다. 파싱 실패나 코드 불일치는 사용자 확인 또는 수정 대기 상태로 표시합니다.

## 결과

같은 소스로 제출한 별개 ID도 각각 보존할 수 있습니다. 동일 ID를 다시 받아도 중복 커밋을 만들지 않도록 SQLite 고유 제약과 Git 복구 표식을 사용합니다. 제출 스냅샷의 소스와 채점 메타데이터는 각각 별도의 수명을 갖습니다.
