# ADR 0003 · 전용 Git clone과 SQLite 복구 큐

## 맥락

여러 제출을 독립적으로 보존하면서 브라우저 재시작이나 Push 실패 후에도 같은 커밋을 재사용해야 합니다.

## 결정

Native Core의 사용자 데이터 경로에 전용 clone을 두고 SQLite에 제출과 동기화 작업을 보존합니다. 원격은 사용자가 명시한 GitHub 저장소와 브랜치로 제한합니다. Git CLI는 기존 사용자 인증을 사용합니다. 커밋 대상은 동기화에 필요한 경로로 명시합니다.

## 결과

Git 명령을 SQLite 트랜잭션 밖에서 실행합니다. 재시작 시 Git 상태와 SQLite 작업을 대조합니다. 관리 clone에서 의도하지 않은 변경을 발견하면 동기화 오류가 표시됩니다. 채점 메타데이터 갱신 시 새 커밋을 생성하여 제출 소스와 기존 커밋을 보존합니다.
