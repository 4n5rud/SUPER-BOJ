# ADR 0008 · 정답 제출 자동 가져오기

## 맥락

ADR 0002의 수동 연결(제출 준비, 내 제출 연결, 공식 코드 붙여넣기, 제출 확정)은 단계가 많습니다. GitHub 자동 동기화를 켰는데도 확정 단계를 거치지 않아 아무것도 올라가지 않는 일이 실제로 있었습니다(2026-11-27, 1330번). 백준허브는 정답이 나오면 제출 코드를 따로 요청해 바로 업로드합니다.

## 결정

사용자가 GitHub 저장소를 연결하고 자동 동기화를 켠 경우에만 다음을 합니다.

1. 백준 채점 현황 페이지가 열리면, 로그인한 본인의 제출 중 자동 업로드를 켠 시각 이후에 제출했고 `맞았습니다!!`(영어 화면은 `Accepted`)이며 지원 언어인 행을 찾습니다. 페이지가 채점 결과를 갱신하면 10분 동안 다시 확인합니다.
2. 아직 올리지 않은 제출이면 사용자의 로그인 세션으로 `/source/download/<제출 번호>`와 `/problem/<문제 번호>`를 한 번씩 읽습니다. 켠 이후에 새로 맞은 제출만 올리고, 예전 정답을 한 번에 올리지 않습니다. 켠 시각은 확장이 브라우저에 기록하며, 제출 시각을 읽지 못한 행은 올리지 않습니다. 백준 요청 사이에는 1초 이상 간격을 둡니다.
4. 자동 업로드 체크박스는 기본으로 켜져 있습니다(사용자 결정, 2026-11-27).
3. 로컬 Core의 `IMPORT_ACCEPTED_SUBMISSION`으로 저장하고 동기화 큐에 넣습니다. 같은 제출 번호는 한 번만 저장합니다.

제출 요청 전송과 제출 버튼 클릭은 여전히 하지 않습니다. ADR 0002의 수동 연결은 오답 기록과 자동 가져오기가 꺼진 경우를 위해 남겨 둡니다.

## 결과

- 정답 제출이 사용자 조작 없이 GitHub에 올라갑니다.
- 열린 페이지 외의 백준 페이지를 읽게 됩니다. 백준 이용 규칙은 웹 스크래핑을 금지하므로, 요청 수를 본인 정답 제출당 2회로 줄이고 자동 동기화를 켠 사용자에게만 동작하게 했습니다. Chrome 웹 스토어 설명과 개인정보 안내에 이 동작을 밝혀야 합니다.
- 오답과 지원하지 않는 언어는 자동으로 올리지 않습니다.
