# ADR 0004 — 제출 소스의 검증과 로컬 저장

제출 준비 시 편집기의 언어와 소스를 사용자별 SQLite에 저장한다. 준비 UUID는 재시도의 멱등성 키다. 준비 기록이 실제로 연결되기 전까지 이력과 Git 큐에는 나타나지 않는다.

제출 확인 시 요청의 계정, 문제 번호, 제출 번호와 공식 페이지에서 확인한 코드를 저장된 준비 기록에 대조한다. 코드는 UTF-8 바이트를 그대로 비교하며 SHA-256 해시와 함께 저장한다. 계정이 확인되지 않은 상태에서 준비한 경우 실제 제출을 연결할 때 공식 기록의 계정을 명시적으로 확인한다. 코드가 다르면 `SUBMISSION_MISMATCH`를 반환한다.

준비 UUID마다 한 건을 연결할 수 있다. 동일 계정과 제출 번호에 대한 재전달은 같은 문제와 소스일 때 멱등적으로 응답한다. 소스가 같은 별개의 제출은 각각 보존한다. SQLite 트리거는 제출의 소스, 언어, 계정, 문제, 제출 번호를 고정한다.

제출 확정 및 판정 정보 변경은 Git 큐 등록을 같은 즉시 쓰기 트랜잭션에서 처리한다. Git 명령은 트랜잭션 외부에서 실행한다. 이력 목록은 커서 기반으로 소스를 제외해 페이지를 반환하고, 상세 요청에서만 소스를 반환한다.

기록되지 않은 제출 시각, 실행 시간, 메모리는 null로 둔다. 알 수 없는 판정 문자열은 그대로 저장하며 정규화한 판정에는 UNKNOWN을 사용한다. 판정이 변경되면 메타데이터 개정 번호를 올리고 제출 소스를 그대로 유지한다.
