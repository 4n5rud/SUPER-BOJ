# 이슈 초안 · 로컬 디버거 첫 버전

예제나 사용자 입력에 대해 코드가 어느 줄에서 멈췄고 현재 변수가 어떤 값을 가지는지 사이드 패널에서 확인할 수 있게 한다.

## 첫 버전 범위

- C++17 한 언어에서 시작한다. macOS arm64에서 LLDB 계열 도구로 중단점, 한 줄 실행, 변수 조회가 가능한지 먼저 검증한다.
- 문제별 초안의 실행 사본으로 디버그 세션을 시작한다. 예제 또는 사용자 입력 한 건을 넘기고, 편집기에서 파일 한 개의 줄 중단점을 설정한다.
- 시작, 계속, 한 줄 실행, 중지와 현재 줄, 지역 변수, 표준 출력 및 오류 출력을 제공한다.
- 시작 전에 도구 설치 여부를 표시한다. Windows와 Linux, 다른 언어, 조건부 중단점, 변수 수정, 표현식 실행은 후속 이슈로 다룬다.

## 구현 계획

1. Rust Core에서 디버거 탐지, 고정된 컴파일·실행 인자, 임시 작업 디렉터리와 세션 정리를 검증한다.
2. 현재 초안과 디버그 중인 소스가 다른 경우를 표시한다. 실행 중 편집한 소스는 다음 세션부터 사용한다.
3. Native Messaging에 세션 시작·상태 조회·계속·한 줄 실행·중지를 추가한다. 실행 중인 세션 ID로 요청을 확인하고 Rust·TypeScript 검증과 공유 요청 예시를 갱신한다.
4. 편집기에서 중단점과 현재 줄을 표시한다. 멈춘 세션에서만 계속과 한 줄 실행을 제공한다. 디버그 기능이 완성되면 전용 아이콘을 편집기 도구막대에 연결한다.

## 완료 조건

- 사용자가 두 개 이상의 줄 중단점을 설정하고, 계속과 한 줄 실행으로 이동한 위치 및 현재 지역 변수를 확인할 수 있다.
- 세션 시작, 멈춤, 종료, 컴파일·도구 오류를 구분해 표시한다.
- 명시적 중지, 브라우저 연결 종료, 시간 및 출력 제한 도달 시 디버거와 자식 프로세스를 정리한다.
- 새 세션을 실행할 때 이전 세션의 상태가 섞이지 않는다. 기존 로컬 테스트, 초안, 제출 스냅샷과 Git 동기화 경로를 유지한다.
- 자동화 테스트와 실제 Chrome 사이드 패널에서 한 예제의 디버그 흐름을 검증한다. 실제로 확인한 운영체제와 도구 버전을 기록한다.
